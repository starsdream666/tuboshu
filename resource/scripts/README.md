## 使用步骤

### 方式一：在Tuboshu中配置（推荐）

1. **打开Tuboshu应用**

2. **添加或编辑Silly Tavern网站**
   - 点击左侧菜单中的"+"按钮
   - 或点击已有网站的编辑按钮

3. **复制脚本内容**
   - 打开 `auto-auth-401-sillyTavern.js` 文件
   - 复制全部内容

4. **粘贴到JS脚本字段**
   - 在网站编辑界面中找到"JS脚本"字段
   - 将脚本内容粘贴进去

5. **修改凭证信息**
   - 在脚本中找到以下两行：
     ```javascript
     const USERNAME = 'star';
     const PASSWORD = 'boyu123456789';
     ```
   - 根据需要修改用户名和密码

6. **保存配置**
   - 点击保存按钮

### 方式二：直接在浏览器控制台运行

1. 打开Silly Tavern网站
2. 按 `F12` 打开开发者工具
3. 切换到"Console"标签
4. 复制脚本内容并粘贴到控制台
5. 按 Enter 执行

## 脚本工作原理

### 401错误检测机制

脚本使用多种方式检测401错误：

1. **DOM文本检测**
   - 检查页面中是否包含 "401"、"Unauthorized"、"身份验证" 等关键词

2. **HTTP响应状态检测**
   - 拦截 Fetch 请求，检查响应状态码是否为 401

3. **页面变化监听**
   - 使用 MutationObserver 监听DOM变化，实时检测401错误

### 认证流程

```
页面加载
  ↓
检测是否为401错误
  ↓
是 → 构建带凭证的URL
  ↓
重定向到认证URL
  ↓
服务器验证凭证
  ↓
认证成功，页面正常加载
```

### v2.0版本完整流程

```
1. 访问 → https://sillyTavern.example.com
     ↓
2. 检测401错误
     ↓  
3. 自动重定向 → https://star:boyu123456789@sillyTavern.example.com
     ↓
4. 服务器验证凭证成功
     ↓
5. 等待2秒（可配置）
     ↓
6. 自动清理URL → https://sillyTavern.example.com
     ↓
7. 最终页面：干净的URL，已认证状态
```

### 构建认证URL的方式

```javascript
// 原始URL
https://sillyTavern.example.com/api/data

// 构建后的认证URL
https://star:boyu123456789@sillyTavern.example.com/api/data

// 清理后的URL（v2.0新功能）
https://sillyTavern.example.com/api/data (保持认证状态)
```

## 常见问题

### Q1: 脚本没有自动触发怎么办？

**A:** 按以下步骤排查：
1. 确保脚本已正确粘贴到"JS脚本"字段
2. 检查浏览器控制台（F12）是否有错误信息
3. 尝试手动刷新页面（Ctrl+R）
4. 检查用户名和密码是否正确
5. **推荐**：使用 `auto-auth-401-debug.js` 调试版本查看详细日志

### Q2: 认证成功但URL清理不工作怎么办？

**A:** 排查步骤：
1. **使用调试版本**：将 `auto-auth-401-debug.js` 复制到JS脚本字段
2. **查看控制台**：按F12查看详细的调试信息
3. **检查URL格式**：确认认证后的URL确实包含 `username:password@` 格式
4. **尝试简化版本**：使用 `auto-auth-401-simple.js` 简化版本
5. **调整延迟时间**：将 `CLEANUP_DELAY` 改为更长时间（如5000ms）

### Q3: 脚本执行了但还是显示401怎么办？

**A:** 可能的原因：
1. 用户名或密码错误 - 检查凭证信息
2. 服务器不支持URL中的凭证格式 - 尝试使用HTTP Basic Auth认证（需要服务器支持）
3. 服务器有其他认证机制 - 检查服务器配置

### Q3: 如何在多个网站使用不同的凭证？

**A:** 为每个网站创建不同的脚本副本：
1. 复制脚本文件，重命名为不同的名称
2. 在每个副本中修改不同的用户名和密码
3. 在Tuboshu中为不同的网站配置不同的脚本

### Q4: 脚本会记录密码吗？

**A:** 不会。脚本只在浏览器内存中运行，密码不会被保存到磁盘或发送到外部服务器。

## 安全建议

1. **凭证管理**
   - 不要在公共计算机上使用此脚本
   - 定期更改服务器密码
   - 不要将包含凭证的脚本分享给他人

2. **HTTPS优先**
   - 确保使用HTTPS连接，避免凭证在传输中被截获
   - 不要在HTTP（非加密）连接上使用此脚本

3. **备份配置**
   - 定期备份Tuboshu的配置文件
   - 配置文件通常位于用户数据目录
